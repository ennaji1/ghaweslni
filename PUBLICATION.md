# Livraison du projet de docking

Sources du projet E-Wslni-Autonomous-Guide-Robot, modifications de simulation et essai matériel, modèle distillé v2 et documentation.

Origine du robot : https://github.com/RedaMohssine/E-Wslni-Autonomous-Guide-Robot

Voir GUIDE_ROBOT_REEL.md pour Ubuntu 22.04 / ROS 2 Humble sans Docker. Le modèle est expérimental, validé en simulation avant contact, pas sur le matériel.

Les données brutes d'essais (9,2 Go), les caches et sauvegardes temporaires ne sont pas inclus ; le modèle retenu et son rapport sont inclus.
